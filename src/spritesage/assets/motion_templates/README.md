# Bandit motion template

`bandit.glb` is a starter Humanoid template created by the Sprite Sage project owner using Meshy on a paid plan. The project owner believes the reference image was generated with OpenAI. It contains the Walking, Running, Run_03, and Dead animations. Sprite Sage distributes this asset as part of the application and installs a content-addressed copy in application data on first use.

Meshy: https://www.meshy.ai/
